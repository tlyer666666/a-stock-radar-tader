## 🎯 项目定位

**A-Share Quant Radar（A股雷达）** 是一套本地优先的跨平台桌面研究工作台，覆盖 **沪深主板、创业板、科创板、北交所非 ST A 股** 以及 **场内 ETF、可转债** 的实时行情跟踪、全市场规则选股、AI 深度研判、盘中做T辅助与可审计历史回测。

核心工程准则：

1. **数据源主次分明、熔断共享**：固定以 **同花顺（扶摇官方接口 + 免费网页网关）为主源**，**东方财富为次源**，**腾讯 / 新浪 / 搜狐为交叉校验与故障接力**；单路限流自动指数退避熔断并展示直白中文状态。可转债、北交所这类大名单的行情先读腾讯批量快照、取不到的再用同花顺逐只补齐；个股行情、预警与止损仍走同花顺优先链路。
2. **全市场选股可追溯、不伪造数据**：策略选股扫描全市场约五千余只合格 A 股（依托本机 `daily-bars` 增量日线库），缺失字段保持 `null`/`暂缺`，绝不把缺失涨跌幅显示为 `0.00%` 或用 `收盘价 × 成交量` 伪造成交额。
3. **回测与模拟严守 A 股交易制度**：严格执行交易所休市日历、次日开盘/区间可成交性、一字涨跌停阻断、`T+1` 交收、科创板 200 股 / 北交所 100+1 股手数约束以及双边税费滑点核算。

## 🧠 策略选股与回测

### 全市场策略选股与本地增量日线库

- **扫描范围**：覆盖沪深主板、创业板、科创板、北交所全部非 ST、`*ST` 及非退市整理 A 股（上市满 120 个交易日），无 300 只数量上限。
- **本地日线库（`userData/daily-bars`）**：首次全市场选股按批下载不复权日线并落盘（中途取消亦保留已下进度）；此后每个交易日优先使用全市场名单自带收盘快照或同花顺扶摇批量快照（经收盘时点、昨收连续性、真实成交与量额单位一致性校验）直接补齐最新一根，日常选股仅需数秒至十余秒。
- **精选与自定义策略**：按 2021–2026 全市场实盘口径回放筛选出 7 条核心精选策略置顶展示，其余在用策略归入「更多策略」；支持声明式条件编辑器或用大白话由 AI 辅助生成「我的策略」（可选全市场或仅扫自选与持仓）。

### 单股回测与共享现金组合回测

- **单股回测**：支持单策略或多策略同日投票阈值，默认按信号次一主市场交易日开盘成交；自定义限价仅在落入次日真实 `[最低价, 最高价]` 区间内才计成交，一字涨停及停牌日严格阻断，不虚构收益。
- **组合回测**：最多 30 只股票共用单一现金账户回放，遵守整手约束、最大持仓数与单股仓位上限；当日平仓资金次一交易日方可复用，杜绝未来资金提前开仓。

## 🏗️ 技术架构与安全基座

```mermaid
flowchart LR
  UI["React 19 桌面界面<br/>src/features/*"] --> IPC["契约化受控 IPC<br/>electron/ipc/*"]
  IPC --> Svc["模块化服务层<br/>electron/services/*"]
  Svc --> THS["同花顺 · 主源<br/>扶摇接口 & 免费网关"]
  Svc --> EM["东方财富 · 次源<br/>含并发受控 curl 兜底"]
  Svc --> Public["腾讯 / 新浪 / 搜狐<br/>原价交叉核验 & 接力"]
  Svc --> Bars["本地日线库 daily-bars<br/>0600 增量缓存"]
  Bars --> Worker["Worker 工作线程<br/>分批选股 & 组合回测"]
  IPC --> AI["AI 选股 / 问股 / 复盘<br/>多套 OpenAI 兼容模型"]
```

| 层级 | 技术栈与职责 |
| --- | --- |
| **Renderer** | React `19.3`、TypeScript `5.9`、Vite `8.3`；按业务域拆分的 `src/features/*` 工作区与独立复盘双入口 |
| **Desktop & IPC** | Electron `44.9`；单实例锁、`workAreaSize` 自适应窗口、沙箱化 `contextBridge`、`electron/ipc/*.ipc.cjs` 全通道结构化校验 |
| **Services** | Node.js 零第三方运行时依赖服务层（`electron/services/*`）；多源行情编排、共享熔断器、有界内存缓存、公告与短线生态聚合 |
| **Compute** | 独立 `worker_threads` 工作线程池；全市场 400 只分批特征计算、单股/组合历史回放与趋势研究 |
