# A股雷达

一个以涨停股票为默认工作池、自动剔除 ST 与退市风险股的 Windows 桌面监控软件。观察池覆盖涨停后的 T+1 至 T+10，并将个股结构、板块强度、公告信息和市场环境组合为 MRS 主线共振评分；ETF 与可转债作为搜索专属行情标的接入。

## 已实现

- A股、场内 ETF、可转债按代码、名称、拼音实时搜索，结果明确标注证券类型
- ETF 与可转债默认不进入涨停池、观察池、连板池和自动交易信号，只在主动搜索时显示
- ETF 与可转债支持实时价格、多周期 K 线和趋势结构查看，并按数据源价格精度正确解析三位小数
- 搜索与监控自动剔除 ST、`*ST` 和退市风险股票
- A股涨停策略仅接受近 60 个交易日出现过涨停事件的股票
- 手工搜索、自选、持仓与多股同列可分析任意非 ST A 股；近期没有涨停时只跳过 T+ 节点、封板质量等事件因子，实时行情、趋势、量价、板块比较、专业复盘与回测仍正常返回
- 涨停池盘中通过专题接口交易日确认，不再依赖可能滞后的日 K 末条；手动刷新会绕过当日缓存，并显示数据日期、核对时间、来源与股票数。同花顺负责主池，东方财富按代码补齐行业、成交额、市值、首次封板与开板次数并补入同花顺遗漏的北交所股票；同花顺合法空池也不会遮蔽东方财富当日非空池
- 首页顶部自动载入最近交易日涨停池
- 涨停池默认保持紧凑，可展开查看和搜索当日全部涨停股票
- 涨停池逐股显示实时行情、封板数据、结构质量分与可追溯分析标签，并可直接进入完整分析
- 独立“策略信号”板：18 套预定义策略（14 套基础策略、4 套固定组合策略）分别展示验证证据与各自股票；其上新增“稳健优选组合”，只从开发期达标的低重叠基础策略中选取 2–4 套，同股同日至少 2 票才形成共识信号
- 策略信号使用最多 300 只真实涨停观察域证券，并额外加入 120 只不属于当前涨停池的主板、创业板、科创板、北交所分层宽基样本；每只回放 720 根不复权日线（约最近 3 年）并对比中证全指。当前候选池继承软件的数据源策略（同花顺主源、东方财富补全及故障回退），切换数据源后会重新进入后端分源缓存，不沿用旧页面结果；宽基样本获取不足时，稳健优选组合只保留审计结果，不发布股票
- 回放严格核对中证全指主市场日历，只有信号后的下一主市场交易日存在可成交 K 线才按开盘入场；停牌后跨日复牌不会冒充 T+1。固定 5 日持有并扣除简化双边佣金/滑点，成本尚未覆盖最低佣金及按历史日期变化的税费。训练与样本外边界会清洗持仓跨界样本，四段走步窗口也采用同样的防泄漏清洗。计算全部位于独立工作线程，大批量策略历史不进入全局行情缓存；每只股票的涨停索引与逐日特征只计算一次并由 18 套策略共享，避免重复扫描阻塞 CPU
- 组合选优只使用终端留出日期之前的数据，并按样本外平均收益 95% 单侧下限、相对中证全指超额、走步通过率、稳定性、回撤和退化程度评分；最后约 20% 独立信号日期只负责终端考试，不参与策略挑选
- 通过中证全指当时可见的 MA20、MA60 与 20 日收益，将市场分为趋势进攻、震荡均衡、退潮防守；当前市场状态缺少达标历史优势时不发布信号。策略间以同股同日信号包含率去重，默认上限 68%
- 发布门槛不可由前端放宽：总样本不少于 120、样本外不少于 36、独立信号日不少于 60、至少 4 个连续窗口且通过率不低于 2/3；全部样本、样本外、每个走步窗、市场状态、组合开发期与终端留出都必须逐笔具备完整中证全指基准，少一笔也只能诊断、不能通过或发布。样本外超额与 95% 收益下限还必须为正。缺少真实 K 线、仅有外部布尔标签或小样本均不能生成可发布股票
- “回测中心”采用策略优先流程：先选择一套策略或多策略最低票数组合，再从策略信号页本轮已发布命中生成对应股票池，可保留单只、部分或全部（性能上限 30 只），手工搜索只作补充验证。收益窗口固定为最近 120 根日线（约半年），在一个共享现金账户中逐日回放；另取 80 根仅作指标预热、不进入收益窗口
- 结果除账户权益曲线、最大回撤、基准超额、每股贡献与逐笔明细外，还按历史信号日期列出测试范围内当时命中策略的股票及其成交、拒绝或待观察状态。策略生成池与手工篮子分别标识；前者不再误报为“手工先选股”，但仍明确披露当前候选队列不是完整历史时点全市场成分，不能消除幸存者偏差
- 多股回测不会把各股票收益简单平均，也不会删除全部重叠交易；上午开仓只能使用前一交易日结束后的现金与空闲席位，当日收盘退出所得从下一交易日才可复用。结果固定标为“组合诊断”，不会冒充跨股票验证通过
- 单股策略回放保留为组合结果的明细复核入口，支持股票名称或 6 位代码；从个股、策略信号或稳健优选组合进入时，会明确带入所选股票、策略规则、组件与投票门槛。策略信号回放严格复用 robust-v2 同名规则，不会被设置页分析因子替换，也不会污染全局设置
- 三线行情：同花顺 QuantAPI 为默认主源；东方财富与腾讯公开行情并行交叉校验。同花顺实时、历史行情和公告均按官方 `tables[0].table` 契约解析，并在截取历史窗口时保持日期与OHLCV同索引；主源未配置、返回无效、超时或权限不足时，免费通道自动接力且保留三路状态；K 线失败时自动切换腾讯或新浪，涨停专题池失败时自动切换同花顺公开涨停池
- 独立“多股同列”：最多 6 只股票并排比较行情、1/3/5 日收益、MRS、策略、均线、量价、关键支撑、板块、历史复核与风险项
- 多股同列仅对新增股票执行重型分析，15 秒轻量刷新报价；手动添加或删除的股票会持久保存在本机，退出软件或重启电脑后自动恢复
- 独立“自选板块”：涨停池的“监控”和个股页的“加入自选”统一保存到本机自选，可随时移除
- 观察池自动汇总涨停后 10 个交易日内的全部涨停股，并按 T+1 至 T+10 完整分类
- 从“全部十日”或 T+1 至 T+10 任一分类打开个股后，分析页提供对应返回按钮并保留原分类
- 从涨停池、自选、板块强度、资讯雷达或顶部搜索打开个股，也会返回进入前的原页面
- 个股分析采用独立页面，只显示当前股票信息，不再重复展示当日涨停池
- 软件持续运行时每60秒重建近10日观察池，不必退出重开才能纳入新涨停
- 当日连板池独立展示二连板及以上股票，注明连板高度、所属板块、首次封板、开板次数和换手率；开板次数与换手率支持升降序
- 1/5/15/30/60/120分钟、日线、周线、月线蜡烛K线，按周期提供合理日期范围
- K线支持可视密度、前复权/不复权、历史窗口拖动、悬停十字线、OHLCV和价格/日期刻度
- K线支持自由开启 MA5/10/20/60、BOLL、VOL、MACD、KDJ 和 RSI；MA/BOLL 叠加主图，振荡指标在同一 K 线图表组件内对齐显示，选中按钮采用高对比状态
- 实时价格、涨跌幅、换手率、成交额查询
- 动态识别主板、ST、创业板、科创板、北交所涨停价
- 自动寻找最近涨停事件和 T+3/5/7/9 交易日节点
- 涨停日最低价、AVWAP、MA5/10/20/60、均线发散、量能倍数、相对换手、最大回撤
- 涨停板块排行榜展示最多 15 个主要涨停板块，榜单内部滚动；对比中证全指与沪深300的 1/3/5 日超额收益
- 板块近15日强弱轨迹同步显示每日成交量能、15日均量对比与最新5日量能热度
- 板块强度增加内部质量复核：上涨股成交参与占比、主力净流入广度、前五大成交集中度、成分涨幅中位数、涨跌离散度和字段覆盖率共同校验平均涨幅，避免少数龙头独撑时高估整个板块
- 支持搜索任意行业或概念板块（如 CPO），展示强度评分、指数对比、涨停股及全部成分股明细
- 任意行业或概念均可用免费行情成分股的行业字段与交叉概念字段动态生成细分，不依赖 QuantAPI，也不使用固定行业模板
- 配置同花顺 refresh token 后可追加问财“所属同花顺概念”增强；查询失败时自动回落免费细分
- 板块涨停梯队：首板、连板高度、昨日晋级率、炸板率和梯队状态；炸板源不可用时明确显示缺失并暂停风险评分，不再把取数失败伪装成 0 只炸板
- 首板质量评分：首次封板、最后封板、开板次数、涨停换手、封单和位置
- 19 种监控策略自由勾选，新增平台突破首板、波动压缩平台和筹码锁定；风险否决始终启用，并提供五套快捷组合
- 个股不复权历史回放：信号次日开盘模拟入场，连板去重、一字涨停不可成交样本剔除，分别统计1/3/5日结算数、95%胜率区间和相对中证全指的5日超额收益
- 独立准实时资讯雷达：全市场、涨停池、观察池、当前个股、当前板块五种范围
- 财联社电报、7×24 快讯、全市场公司公告、同花顺公告（配置后）聚合、去重、时效和风险分级
- 资讯可信度、影响方向、重要性和行情确认状态分开显示
- 重大资讯自动语音播报：只播报新出现的高重要性、重大风险或 A 级高可信事项，可在顶部或设置中关闭
- 当前报价3–30秒轻量刷新、涨停池15秒自动刷新、财联社与快讯约6秒缓存、公告15秒复核，重型策略分析独立降频
- 多源数据校验在后台执行：所选主行情先显示，腾讯公开行情后台复核；可选 Tushare Token 复核盘后日线
- 本地观察池、自动刷新、数据源设置；收藏在 500 条观察池上限中优先保留，主进程 JSON 与多股同列、回测篮子、纸面模拟、复盘档案等浏览器数据均保留 last-good 恢复副本
- 同花顺 QuantAPI refresh token 接入及免费行情自动降级
- 专业复盘升级为八维市场状态与 20 因子个股诊断：在原有结构、量价、主线、历史与风控因子上增加关键数据完整度、多源行情一致性、独立证据共振和失效边界清晰度；确定性分只衡量证据质量，不代表未来收益概率
- 个股复盘继续展示 1/3/5/10 日走势、ATR、波动收敛、20/60 日区间、关键价位地图、复核清单与次日三情景推演；确定性因子与最终交易预案共用同一确认价、失效价和目标价口径
- 专业复盘显示因子覆盖率、真实数据源、待增强项和独立诊断分；缺失值不按 0 分计算，也不会把 `volumeRatio=0` 误判为健康缩量
- 自绘 Windows 窗口控制支持最小化、最大化/还原和关闭；统一本地字体层级，并将侧栏“系统”分区下移
- 专业复盘、窗口控制与 ETF/可转债差异界面已并入主 React 架构，不再通过第二个界面根节点或全局 DOM 观察器注入；市场笔记与个股笔记独立保存
- 单股与组合回测前后端统一固定为最近 120 根日线（约半年）；三年数据只用于全市场策略验证，两个口径不再混用
- 切换股票时先清除上一只股票结果；加载失败会显示目标股票、原因和重试入口，不会把旧行情误当成新股票
- 桌面端启用单实例保护、组件级故障保护、渲染进程受控恢复和脱敏轮换错误日志；重复双击不会产生两个进程争抢同一份自选、持仓或设置文件
- 启动初始化按模块降级：某一个本地数据或行情接口失败时，其余已就绪页面仍可继续使用；证券搜索也会隔离过期请求，避免旧结果覆盖新输入

## 开发运行

```powershell
pnpm install
pnpm dev
```

## 直接启动已更新程序

双击项目根目录的 `启动A股雷达.cmd`，或直接运行 `程序/A股雷达.exe`。

## 构建 Windows 便携版

```powershell
pnpm build
```

成功构建后完整运行目录位于 `release/win-unpacked`。构建并安全部署到日常使用的正式目录请运行：

```powershell
pnpm build:deploy
```

构建会先写入独立暂存目录，生成逐文件 SHA-256 清单并完成自校验，再原子替换 `release/win-unpacked`；构建中断时会保留最后一个完整产物。构建和部署共用互斥锁，禁止两个任务并发改写产物。

部署会先在临时目录完整复制并校验，再替换 `程序`；如果目录原子改名暂时不可用，降级复制也会先复制并核验所有运行文件，把主程序保留为不可启动的临时名称，最后才原子发布 `A股雷达.exe`。启动时会恢复上次中断留下的完整旧版本；新正式版校验成功后，即使旧版本目录清理失败，也只记录待清理项，不会删除或回滚新版本。如果 A股雷达仍在运行，部署会明确停止。日常使用直接运行 `程序/A股雷达.exe`。

`qa/migrate-to-d-v068.ps1` 是历史迁移文件，现已永久停用并只保留安全提示，不得用于当前版本的部署或清理。

## 可选同花顺增强

1. 注册或登录 iFinD 账号。
2. 打开同花顺“超级命令”网页或 Windows 客户端。
3. 在“工具 → refresh_token 查询”或“账号详情”取得 refresh token。
4. 在软件“数据源设置”中选择“同花顺 QuantAPI”，粘贴 token，测试连接后保存。

核心行情、板块搜索和细分概念无需 QuantAPI。Token 使用 Electron `safeStorage` 加密并仅保存在本机用户数据目录；同花顺不可用时自动降级到免费行情。

> 软件仅用于行情研究和信号监控，不构成投资建议，不包含自动交易。
