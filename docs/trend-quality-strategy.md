# 趋势质量策略升级方案

2026年9月30日  趋势质量策略第二版

本次升级保留全 A 股剔除 ST、近期涨停、上升趋势和目标持有 2—6 周的研究目标。在原版规则之上增加可解释的信号质量约束、次日突破下限和版本化快照，并通过原始日线预筛减少不必要的复权行情请求。原版 classic-v1 继续作为对照。

已经实现的是筛选、人工计划复核和独立信号样本评估。更严格的条件可能减少噪声，也可能错过机会；目前没有独立真实样本证明质量版收益更高。参数预设名称和排序位置均不代表胜率、盈利概率或投资评级。

## 1 原版的主要局限

原版 A 形态只需此前三日某个低点接近 MA20、三日均量相对涨停日缩小，并在当日收盘突破昨日高点。它没有要求越过此前三日整体高点，单个涨停日的异常巨量也可能让普通成交看起来像缩量。

原版 B 形态使用固定 10% 平台宽度，信号统一要求不超过 MA20 的 10% 偏离。同一百分比对不同波动证券含义不同。原排序又仅看20日超额涨幅、成交额和代码，观察股可能排在完整信号之前。

原计划只有止损 S 和最高入场 Pmax。拟成交价跌回突破位、但仍高于 S 时，也可能满足原仓位公式。新版本增加冻结的最低入场价，补上这一执行衔接。

## 2 原版基础条件继续生效

最近15根交易日内有收盘涨停，最近一次为 t0，距当前 d 为0至14；新涨停会重置 t0。收盘价高于 MA20，MA20 高于 MA60，且 MA20 高于5个交易日前。t0 后各日收盘不得跌破 t0 最低价，近20日平均成交额至少2亿元。

A 形态仍使用涨停后第4至14日、三日回踩及原缩量和放量条件；B 仍使用第4至11日、3至10根整理及原突破条件。原10%偏离、原风险区间和指数市场门槛继续保留。质量版不能把原版的排除、数据不可用或观察结果升级为信号。

## 3 质量版新增规则

评价日记为 t。均线、ATR、平台高低和成交量基准只读取不晚于 t 的数据。质量检查在原版候选上追加证据；只有原版已经是 signal，且以下适用条件全部通过，质量版才保留 signal 与计划。否则保留 watch，plan 为 null。

### 趋势与市场相对表现

MA60 不低于5个交易日前。个股20日收益减去同期中证全指收益必须严格大于0；两端按同一交易日对齐。质量版按未舍入数值判定和排序，详情展示6位小数，避免很小的正值被显示舍入变成零。指数市场门槛仍为中证全指收盘不低于 MA60，缺少基准时不能生成入场计划。

### 昨日波动与当日收盘质量

昨日 ATR14 取截至 t−1 的14个真实波幅的简单平均。单日真实波幅为“最高减最低、最高减前收的绝对值、最低减前收的绝对值”三者最大值。今日行情不进入这14项，因此今日放大振幅不能放宽自己的 ATR 容忍范围。昨日 ATR 必须大于0。

收盘价与当日 MA20 的距离除以昨日 ATR14，不超过 maxExtensionAtr。当日必须有非零振幅，收盘位置“收盘减最低，再除以最高减最低”至少达到 minCloseLocation。当日成交量除以此前五日均量，不超过 maxVolumeRatio。

### 承接与常态缩量

此前三日至少两日收盘不低于各自 MA20。成交量中位数使用此前20日，包含期间涨停日，但不含信号日；中位数降低单个异常成交日对基准的影响。原始与前复权收盘比相对当前因子的变化，在这20日和信号日合计21根中均不得超过0.2%。

主形态 A 还须收盘突破此前三日最高价，且此前三日均量不超过此前20日成交量中位数。主形态 B 还须平台绝对宽度不超过4倍昨日 ATR，且整理区间均量不超过同一20日中位数。原版自身的涨停日量比条件仍须满足。

### 噪声止损与入场区间

信号收盘至原冻结止损的距离，至少为0.5倍昨日 ATR。新增最低入场价和收紧后的最高入场价还必须形成非空区间。零 ATR、零振幅、任一通用条件失败或主形态条件失败，都不能留下可执行计划。

## 4 参数与入场价格

只开放三个质量参数。未指定策略时，后端兼容调用仍使用 classic-v1；桌面界面默认选择质量版稳健预设。范围外数值、非有限数、未知策略和未知配置键会被拒绝。原版配置为空。

| 参数 | 稳健默认 | 均衡 | 允许范围 |
| --- | --- | --- | --- |
| 最大均线偏离 ATR<br>maxExtensionAtr | 2 | 2.5 | 0.5—5 |
| 最低收盘位置<br>minCloseLocation | 0.70 | 0.65 | 0.50—0.95 |
| 最高五日量比<br>maxVolumeRatio | 3 | 3.5 | 1.2—6 |

稳健与均衡只是可复现的研究预设，不构成收益更高的证据。参数文件为 config/trend-quality-robust.json 与 config/trend-quality-balanced.json。A/B 时间窗、2亿元门槛、4倍昨日 ATR 平台宽度及0.5倍 ATR 风险距离等规则不作为本轮可调参数。

### 保持原止损口径

原冻结止损 S 为 t0 最低价与“形态低点减0.5倍当日 ATR14”中的较高值，再向上取整到分。A 使用此前三日最低价；B 使用 t0 后、信号日前整理区间最低价。这里的止损沿用原版当日 ATR；质量版新增的偏离、平台宽度、噪声距离和入场上限统一使用昨日 ATR，两者不可混称。

A 和 B 同时命中时，primaryPattern 明确为 A，沿用 A 的止损与三日突破位。原 A/B 标签保留，但若 A 的质量条件失败，不允许借 B 的证据继续使用 A 的止损生成信号。只有原版仅命中 B 时，才按 B 的主形态条件复核。

### 冻结次日价格边界

最低入场 minEntry 取“突破位加0.01元”和“S加0.01元”中的较高值，再向上取分。A 的突破位是此前三日最高价；B 的突破位是整理平台最高价。

最高入场 maxEntry 取原 Pmax 与“信号收盘加0.5倍昨日 ATR”中的较低值，再向下取分。原 Pmax 仍受“1.03倍信号收盘”和“S除以0.92”中较低值约束。必须满足 S < minEntry ≤ maxEntry；实际拟成交价低于 minEntry 或高于 maxEntry 时取消入场。

合成单元样例给出的 S 为15.80元，最低入场16.31元，最高入场16.70元。此例仅说明取整和区间约束，不对应真实证券或收益预测。

## 5 风险规则与使用流程

质量版没有改变原仓位和退出纪律，也不会自动下单、建立真实持仓或代替人工核验。卡片中的计划风险是入场价与止损的价差比例，实际损失仍可能因费用、跳空、停牌和无法成交而扩大。

| 保留约束 | 具体要求 |
| --- | --- |
| 单笔风险 | 计划亏损不超过账户净资产的0.5% |
| 仓位上限 | 单股15%  同行业25%  组合总仓60% |
| 持仓数量 | 最多6只  同股持仓未结束前不重复开仓 |
| 价格与数量 | 止损距离不超过8%  扣除费用预留后按已核验数量规则向下取整 |
| 入场前核验 | 核验交易权限 状态 公告 公司行为口径 以及次日开盘窗口 |

### 退出纪律

目标持有10至30个交易日，不是至少持满10日。收盘跌破冻结 S，或持仓后连续两个交易日收盘低于各自 MA20，安排下一可交易日开盘退出。买入日为第1日，第29日收盘安排第30日开盘退出；停牌或跌停造成延迟时不虚构退出。冻结 S 不因普通下跌而下调，公司行为须另行核对价格口径。

### 排序与人工复核

质量版按有效 signal 优先、未舍入20日超额涨幅降序、昨日 ATR 归一化偏离升序、20日平均成交额降序、证券代码顺序排序。原版排序保持原样。排序帮助查看候选，不替代行业集中度、公告或可成交性判断。

扫描前选择策略与参数，扫描后阅读实际返回的版本与配置快照。先核对市场门槛、板块名单及行情覆盖，再查看质量证据和冻结区间。完整名单不等于每只证券的历史数据可用；失败或不可用不得解释成没有机会。

### 计划快照兼容

保存计划冻结候选、策略版本、配置指纹、最低入场、最高入场和止损。新策略计划身份包含版本及配置指纹，避免不同参数互相覆盖；历史原版计划继续使用原标识及原价格。编辑下一次扫描参数不会修改已保存计划，跨策略候选不被当作旧计划的最新确认。

浏览器示例和导出持续标明 DEMO。观察候选可以保存，但没有入场计划；包括零 ATR 在内的不可用质量条件不会因保存而变成有效信号。

## 6 集成接口与扫描性能

策略入口位于 electron/trend-strategy.cjs。normalizeTrendStrategy(options) 校验配置并生成快照；evaluateTrendStrategy(input, options) 返回候选、排除或数据不可用；rankTrendStrategyCandidates(rows, options) 执行对应版本排序。

```js
options = { strategyId: 'quality-v2', config: {
  maxExtensionAtr: 2, minCloseLocation: 0.70, maxVolumeRatio: 3
} }
strategy = { id, version, configHash, config }
```

快照版本分别为 classic-v1 的1.0.0与 quality-v2 的2.0.0。配置指纹是按固定顺序 JSON.stringify({id, version, config}) 计算的 SHA-256；质量配置键顺序为 maxExtensionAtr、minCloseLocation、maxVolumeRatio。候选附 strategy，质量版再附 primaryPattern、quality 和逐条 evidence；仅有效信号拥有 plan。

扫描服务 start(options) 另外接受 forceRefresh 布尔值。缓存键区分策略、版本、参数指纹、证券身份和指数指纹；缓存有效期15分钟，强制刷新跳过结果缓存。取消信号传至行情请求，跨取消重启的真实历史请求并发不超过6，旧任务不得更新新任务状态。

### 原始日线必要条件预筛

prefilterTrendStock 复用原引擎的日线校验与涨停识别。已验证的原始数据足以确定不满足必要条件时，跳过该股前复权请求；否则继续完整评价。坏数据保持 unavailable。理论请求结构由每股两次的2N，变为 N 次原始请求加 M 次通过预筛者的前复权请求。

| 240只合成证券固定夹具 | 完整获取 | 预筛后 |
| --- | --- | --- |
| 原始日线适配器调用 | 240 | 240 |
| 前复权日线适配器调用 | 240 | 24 |
| 历史调用合计 | 480 | 264 |
| 相对完整获取减少 | 基准 | 216次  45% |

夹具每只260根日线，其中24只通过预筛。原版与质量版各自优化前后候选深度一致。调用计数不包括证券名单、指数请求和底层 HTTP 重试；测试没有联网。45%只是该固定数据集的请求量减少，不能称为实盘扫描提速45%，也不能外推真实市场候选比例或收益。

## 7 验证结论与数据边界

软件回归覆盖原版输出对照、参数隔离、质量否决、昨日 ATR 因果性、零波动、价格区间取整、取消重启和计划兼容，最终测试数量以验收记录为准。筛选规则更严谨，不等于收益已经提高。

### 独立信号样本评估

electron/trend-strategy-evaluator.cjs 使用同一数据源分别评价 baseline 和 advanced。信号按日截断，只读取截至信号日数据；最早下一市场日开盘成交。评估处理滑点、费用、开盘涨停拒买、跌停延迟退出、停牌、缺失行情和公司行为核验；无法确认的样本保留为未解决，期末未平仓单列删失。

splitDate 将开发信号与测试信号按日期分开，开发成交也在分界前截止；测试不借用 to 之后行情。报告对象是独立信号交易样本，同股信号允许重叠，没有共享资金账户、仓位容量或行业组合约束。因此它不是组合回测，不报告组合年化或组合夏普，不能据此推断可实盘复制的账户收益。

合成数据报告标为 SYNTHETIC_MECHANICS_ONLY；真实输入也只标为 REAL_DIAGNOSTIC。returnSuperiorityVerified 固定为 false。真实收益优越性须由独立、充分、包含成本和执行限制的数据检验，不能从合成利润、规则复杂度或筛选数量推导。

### 当前公开数据仍有缺口

当前行情适配器缺少历史时点完整证券池，即 point-in-time 或 PIT 名单，以及逐日官方涨跌停价、历史 ST 或不限价交易状态和完整公司行为账本。使用当前存续证券名单回看历史可能带来幸存者或选择偏差。规则推算涨停不能冒称官方确认；真实评估输入缺官方限价来源时，不生成已经可成交的收益结论。

现扫描要求至少250根日线，会限制较新上市证券的覆盖；指数日线仅作为交易日历代理。名单分页、停牌、复权不一致或缺数应显式披露。本轮源端实测仍返回 UND_ERR_SOCKET，全市场真实扫描尚未完成；固定夹具与 DEMO 不能替代这一缺失验证。

### 实现与复现位置

规则与预筛：electron/trend-strategy.cjs、electron/trend-screener-engine.cjs。服务与行情：electron/trend-screener-service.cjs、electron/trend-screener-adapter.cjs。仓位与快照：src/trendPlan.ts、src/trendWorkspace.ts。

性能依据：artifacts/strategy-v2-qa/performance.json 与 performance-report.md；复现脚本为同目录 performance-fixture.cjs。独立信号评估入口为 qa/evaluate-trend-strategies.cjs，输入来源、日期范围、费用配置和诊断标签应随报告保留。
