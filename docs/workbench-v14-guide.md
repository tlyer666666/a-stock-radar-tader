# A股策略研究与界面升级说明

A股雷达 1.4 使用说明  2026年9月30日

本次升级把趋势筛选扩展为14个策略选项，策略信号扩展为32条，增加指定股票测试、同花顺细分行业查询和更完整的专业复盘。导航按工作分组，深浅主题统一层次。选股目标继续是全A股剔除ST，寻找近期涨停后仍处于上涨趋势的股票，研究2至6周波段。

## 1 策略多了以后怎样判断优劣

优质应当表现为足够样本下的稳定性和较好的交易结果，而不是公式多、名称响亮或某次胜率高。本版先把规则、参数、适用形态和验证状态公开，方便比较；新增规则未获得独立真实样本外证据前，不标为稳定高胜率策略。

| 检查项目 | 比较方法 |
| --- | --- |
| 胜率与样本 | 同时看样本外胜率、交易数和独立信号日。少数交易的高胜率不能支持稳定结论。 |
| 收益与代价 | 扣除费用、滑点后检查净收益、基准超额和回撤；频繁交易或无法成交的信号需单列。 |
| 跨阶段稳定 | 检查不同市场状态、证券与走步窗口；避免只选一次行情中的最佳参数。 |
| 数据与执行 | 核对历史状态、公司行为、停牌和涨跌停限制。缺数据不是零风险，也不等于没有信号。 |
| 研究周期 | 信号模块现有5日诊断与目标2至6周验证分别阅读，不能把前者直接当作后者的收益证据。 |

### 策略信号页的实际变化

目录可在整批历史复核结束前使用，支持按名称查找、按验证状态过滤，以及按已有样本外胜率或稳定性排序。缺失指标排在后面；只有满足服务端完整发布门槛的结果进入已验证状态。原样本外、走步、费用及多重试验约束继续生效。

本轮新增策略依据通达信及同花顺公开指标资料独立实现；EOM与唐奇安通道另核对TradingView官方定义。这些组合不是平台官方荐股公式，也没有采用网上宣传的胜率数字。

## 2 趋势筛选的14个选项

原版趋势与趋势质量版继续保留，原有MACD、BOLL、DMI、OBV、KDJ和均线回踩六种指标规则不变。本轮增加以下六种，合计12种指标策略加2种原版或质量选项。默认联合选择质量版与12种指标规则，共13项，可自行取消。

| 新增策略 | 固定触发条件摘要 |
| --- | --- |
| RSI中位修复 | RSI14由不高于50转为高于50，且不超过75；收盘超过昨日最高价。 |
| CCI强势突破 | CCI14上穿100，且收盘超过昨日最高价；偏差使用平均绝对偏差。 |
| ROC动能转正 | ROC12由非正转正，且收盘超过昨日最高价。 |
| EMV量价轻推 | EOM口径的14日均值由非正转正，且收盘超过昨日最高价。 |
| MFI量价修复 | MFI14上穿50且不超过80，收盘超过昨日最高价；这是价量代理，不是真实资金流。 |
| 唐奇安55日突破 | 收盘首次超过不含当日的此前55根最高价，昨日尚未完成对应突破。 |

### 每一种都必须通过共同条件

这些规则不需要原版A或B先命中，但仍须通过近期15根收盘涨停、上涨趋势、锚点支撑、流动性、相对强弱及价格风险等共同约束。缺失窗口、无效成交量、零分母、市场关口不可用或不通过，不能生成有效入场计划。

指标只读取截至评价日的数据。新增趋势规则采用共同固定参数：最大均线偏离3倍昨日ATR，止损窗口5日，最小风险距离0.5倍昨日ATR，入场上限附加0.5倍昨日ATR。完整参数、来源与版本在界面折叠详情及策略配置文件中保留。

### 筛选后怎样使用

先看行情日期、扫描覆盖及失败原因，再看具体命中证据、参考止损和入场区间。同股命中多种规则不表示可以重复叠加仓位。保存计划仍冻结当时策略和价格；之后修改扫描参数不会改写旧计划。

扫描策略区域支持按形态分类、搜索和收起。默认卡片仅呈现名称与类别，详细规则按需展开，减少首屏说明文字和大面积强调色。

## 3 策略信号与指定股票测试

信号规则由24条增加到32条，其中基础形态仍为14条，组合由10条增至18条。以下八组使用不同的形态与指标确认，实际参与匹配、版本快照、验证和回测。

| 新增组合 | 形态与确认 |
| --- | --- |
| RSI回踩共振 | MA10回踩成立，RSI14高于50且不超过75，并较昨日抬升。 |
| CCI突破共振 | 二次突破成立，CCI14上穿100。 |
| ROC收复共振 | 涨停后均线收复成立，ROC12为正且抬升。 |
| EMV地量共振 | 缩量反弹成立，EOM14为正且抬升。 |
| MFI回踩共振 | MA10回踩成立，MFI14高于50且不超过80，并抬升。 |
| 唐奇安突破共振 | 二次突破成立，首次突破前55日通道上沿。 |
| RSI与MFI共振 | 缩量反弹成立，两指标同时满足各自强度区间及抬升条件。 |
| CCI与ROC共振 | 均线收复成立，CCI14高于100且抬升，ROC12也为正且抬升。 |

### 按这条路径测试具体股票

进入“策略信号”，在顶部“指定股票测试”选择策略，输入股票代码或名称，再从搜索结果选中一只股票。确认下方已选股票及当前策略后，点“测试这只股票”；回测中心会带入证券和策略，再设置日期、费用等参数并运行。即使当前没有命中股票，也可以使用这个入口。

只输入文字不等于选中证券。修改搜索词会清除旧选择；旧查询迟到时不能覆盖新结果。支持上下方向键、回车选择和清空，拒绝ST、退市风险名称以及非普通A股身份。

### 解释测试结果

量价组合缺少成交额时，系统尝试获取经交叉核对的真实原价量额；必要字段、连续窗口或基准日期覆盖仍不齐全时，明确返回数据不足，不能解释为零信号。成功返回后仍需查看样本数与验证状态。单股测试不能证明全市场稳定性；真实探针与字段覆盖随验收记录保留。

## 4 从板块到细分产业链

板块页增加独立的分类与来源浏览器：同花顺F10二三级行业、行业行情目录、概念板块和产业链研究各自保留口径。输入任意符合普通A股格式的六位代码，可以查询该股票源页明示的行业路径，再查看报告期同行名单。成分行的“查行业”支持继续深入。

| 入口 | 能够说明什么 |
| --- | --- |
| 二三级行业 | 读取F10明确的行业层级，例如电子到元件到印制电路板。报告期同行不冒充实时完整指数成分。 |
| 行业行情与概念 | 按源页目录发现入口并读取分页成分。源页未写层级时保留层级未标，不推定全部是二级。 |
| 电子布与电子树脂 | 以正式公司披露说明代表企业与PCB产业链的关系，标为人工研究分组。 |
| 原有板块分析 | 仍在“涨停池板块复核与原有分析”中展开使用，原功能保留。 |

### 完整性比一个强度数字更重要

每个详情显示来源、抓取时间、行情日期或报告期、已载入数量、声明总数、分页覆盖、剔除与异常记录。来源失败可显示旧缓存及旧资料标签，不静默换成别的行业。数据源未给出行情日期时，不把抓取时间当成今日行情日期。

本机探针发现461个入口：90个行业行情、361个概念、7个去重后的二三级行业字段及3个人工研究分组。这不是完整的同花顺二三级行业树；任意股票查询用于继续发现。此次PCB概念后续页被源端拒绝，只保留部分数据；印制电路板同行读到47家，源页声明49家，均明确标注不完整。

因此，本版具备真实细分分类浏览与个股联动，但尚不能提供完整、同日期、全成分的同花顺细分行业强度排名。名单缺口和未知行情日期会继续阻止这类完整性声明，不用不可靠数字冒充排名。

### 性能与稳定性

目录与详情分别缓存，请求受并发上限控制；切换目录、修改代码或取消查询时，旧结果不能抢走当前选择。新增严格的表头顺序、分页、重复证券、交易所代码及金额单位校验，避免源网页变化造成错误数值。

## 5 专业复盘与界面改版

### 专业复盘更重证据顺序

复盘依次检查数据可用性、同日市场与板块背景、个股趋势阶段、冲突与失效，最后形成次日条件情景。个股新增8项实测窗口指标和4项有来源的观察价位；风险否决与缺失证据优先呈现，不能被多个相关指标的赞成票冲淡。

趋势延续、分歧整理、防守触发三种情景分别列出条件、需要确认的证据与失效标准。原八维二十因子、历史样本、档案与导出保留。观察价位不会自动覆盖原计划止损，也不会通过评分生成虚构胜率、目标价或仓位。

### 界面和导航

左侧按选股研究、行情跟踪、复盘与信息分组，设置固定在底部，并支持收起为图标。界面统一深灰背景、卡片、边界与文字层次；蓝色用于当前选择或操作，红绿主要表达行情涨跌。浅色模式采用相同的层次规则。

策略选择卡片缩小；参数和说明按需展开。指定股票测试移到信号页前部，策略目录支持搜索、过滤与排序。分别检查760、1024、1480像素窗口，并按截图修正窄窗空白、拥挤与回测策略列表过长的问题。

### 本次审查与交付

三名agent分别负责策略引擎、板块数据与专业复盘及前端审核，再交叉复核。修复涉及异步搜索、设置保存、复盘归档与刷新、启动数据异常、板块表格解析及查询竞态。验收包含单元和契约测试、深浅主题交互、打包程序原生接口及有界真实网络探针；完整记录在桌面验收目录。

桌面a股文件夹保留新应用、源码ZIP、策略配置和本说明。旧版应用及源码移入历史版本备份；原有观察池、计划和设置沿用。没有把预览样本写入真实观察池。
