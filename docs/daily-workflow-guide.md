# 日常研究流程与记录说明

本说明用于当前 A 股雷达工作台的日常研究、计划核对与复盘记录。将行情证据、软件生成的计划和实际执行分开保存，才能区分规则结果、数据问题与执行偏差。软件不自动下单；下列记录可填写在自己的笔记或表格中，不表示应用已提供每个字段的自动归档功能。

具体策略条件、价格计算和参数以所选策略的当前版本及已保存计划快照为准。本说明不另设选股阈值，也不要求所有策略先满足原版 A/B 形态。入口与规则见[工作台使用说明](workbench-v14-guide.md)，质量版的冻结价格和计划兼容见[趋势质量策略说明](trend-quality-strategy.md)，参数文件在[策略配置目录](../config/)。

## 每日流程

| 阶段 | 操作 | 留下的记录 |
| --- | --- | --- |
| 收盘后更新 | 查看行情日期、扫描范围、数据来源和缺失情况，再运行所选策略。分别记录观察候选、有效信号和数据不足。 | 本次策略及参数快照、数据日期、覆盖范围、结果和失败原因。 |
| 计划复核 | 先核对已有持仓及其原计划，再查看新候选。阅读命中证据、公告、市场与行业背景，以及计划的价格和风险字段。 | 待复核事项、候选计划、持仓处理依据及尚未解决的数据问题。 |
| 执行前核对 | 对照保存时的策略和计划，重新确认证券状态、公告与价格口径。将需要人工核实的事项逐一写明。 | 核对时间、核对结果、计划保持或撤销的原因。 |
| 执行后登记 | 如有实际委托或成交，将事实与原计划分别记录；未成交、取消或无法执行也保留原因。 | 委托、成交、费用、滑点、未成交及取消原因。 |
| 定期复盘 | 按策略、版本、市场阶段和行业汇总记录，检查数据缺口、执行偏差与费用影响。 | 周期统计、问题清单；拟修改的规则作为新版本另行验证。 |

同一股票命中多个策略时，保留各自证据和计划身份，避免把多条结果当作不同证券重复记录。修改下一次扫描参数不会修改已保存计划；重新扫描、取消或数据失败也不应被记成实际成交或退出。扫描与回测的取消、后台运行及结果边界见[架构说明](ARCHITECTURE.md)。

## 执行前核对表

- [ ] 证券代码、市场与名称一致；当前证券状态和权限已核对，未把预览数据当成真实行情。
- [ ] 数据日期、复权口径、来源和覆盖范围明确；缺失或旧数据已标记，抓取时间没有被当成行情日期。
- [ ] 已确认所选策略、版本、参数及命中证据；未把观察候选、数据不足或未完成扫描当成有效计划。
- [ ] 公告、停复牌、公司行为及计划相关的市场条件已经核对，尚未确认的事项有记录。
- [ ] 已记录计划中实际存在的参考价格、止损、入场区间、数量和风险字段；不适用项写明原因，不自行补造。
- [ ] 计划与现有持仓、同股其他计划及账户约束已核对；价格和数量单位一致。
- [ ] 未成交、取消或无法按计划执行时的处理依据明确；实际执行如有偏离，另行记录原因，不回写原计划掩盖差异。

## 单笔研究与执行记录模板

| 记录项目 | 填写字段 |
| --- | --- |
| 身份 | 记录编号、证券代码及名称、市场、行业或概念来源。 |
| 策略与时间 | 策略标识、版本、参数快照或配置指纹、信号日期、数据日期、计划保存时间。 |
| 信号证据 | 命中条件、相关指标或价格结构、观察或有效信号状态、数据缺失与风险提示。涨停锚点及 A/B 形态仅在所选策略适用时填写。 |
| 原始计划 | 计划参考价、止损、入场区间、数量、计划风险及其计算依据；未提供的字段注明不适用。 |
| 人工核对 | 核对日期、公告及证券状态、公司行为与价格口径、账户约束、未解决事项。 |
| 实际执行（如有） | 委托及成交日期、方向、价格、数量、费用、滑点；未成交或取消原因。 |
| 后续变化 | 计划调整时间、原因与依据，保留调整前后内容；持仓期间的重要事件及数据问题。 |
| 退出与结果（如有） | 退出日期、触发依据、实际成交与费用、扣费结果、无法成交或延迟情况；最大浮亏等统计附口径与数据范围。 |
| 复盘结论 | 是否按原计划执行、差异原因、数据问题、可复核的经验及下一步验证事项。 |

未成交的计划也可以完成一次研究记录。应用中的观察池、候选、保存计划与持仓分别表达不同状态；不要因保存了候选就记为已买入，也不要因旧候选消失就记为持仓已退出。

## 汇总与复核

保留用于重现结果的策略版本、参数与数据范围后，再比较不同记录。将软件回测、模拟记录与实际成交分开统计；分别列出成功、失败、取消及数据不足，避免只汇总有结果的样本。单股案例或少量记录不能证明策略在全市场或不同阶段稳定有效。

需要研究具体证券时，可从“策略信号”的“指定股票测试”选择证券和策略，再进入回测中心设置日期及费用。完整操作路径和结果解读见[工作台使用说明](workbench-v14-guide.md#3-策略信号与指定股票测试)。
