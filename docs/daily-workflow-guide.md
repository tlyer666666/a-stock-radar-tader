# 日常实盘研究与复盘操作指南（五段式工作流 · v1.6.71）

本指南面向 `A股雷达`（1.6.71）的日常实盘辅助研究、盘中盯盘、计划执行核对与盘后复盘闭环。软件将客观行情证据、规则选股计划、AI 辅助诊断与个人交易记录分层保存：**所有策略、打分与做T信号仅供研究参考，软件不自动连接券商下单**。

相关架构与策略说明请参阅：[项目架构与维护边界](ARCHITECTURE.md) · [趋势质量策略说明（归档参考）](trend-quality-strategy.md) · [交易所休市日历更新手册](operations/market-calendar-update.md)。

## 1. 全天五段式标准工作流（盘前 → 竞价 → 盘中 → 盘后 → 晚间）

| 时段 | 核心入口 | 关键动作 | 沉淀记录与风控纪律 |
| --- | --- | --- | --- |
| **① 盘前准备**<br/>`08:30–09:15` | **今日驾驶舱（盘前模式）**<br/>资讯中心 · 随心记 | 1. 查看隔夜保存的「趋势冻结计划」入场带与止损位、当前实盘持仓与模拟仓状态；<br/>2. 检查「随心记」今日开盘前/竞价提醒待办；<br/>3. 浏览「资讯中心」自选/持仓近 30 日公告，排查停复牌、减持、立案等重大风险；<br/>4. 确认右上角/设置页「数据源状态」三线通畅。 | 确认今日单笔最大允许风险、持仓必守止损价与待观察标的清单；命中重大风险公告标的直接移出候选。 |
| **② 集合竞价**<br/>`09:15–09:25` | **今日驾驶舱**<br/>涨停监控 · 板块强度 | 1. `09:20` 后撤单受限时观察昨日连板梯队龙头、目标股竞价开盘位置与主线板块联动；<br/>2. 对照冻结计划的入场上下限核对开盘价（如涨停次日竞价高开超 4% 或低开超 5% 放弃追入，跳空跌破止损位严禁逆势抄底）。 | 记录竞价强弱分歧（高开承接 / 核按钮 / 板块共振），不把 `09:15–09:20` 可撤虚高封单当作有效确认。 |
| **③ 盘中跟踪**<br/>`09:30–11:30`<br/>`13:00–15:00` | **今日驾驶舱（盘中模式）**<br/>做T助手 · 随心记 · 沪深港通 | 1. 通过驾驶舱统一哨兵监控持仓止损、自选异动与模拟仓状态；<br/>2. 底仓日内波动使用「做T助手与多周期工具箱」：结合分时均价线、波动率轨道、多周期 K 线画线与扣除双边税费后的净价差评估高抛（倒T）/低吸（正T），严格受 `T+1` 今日可卖股数与单边行情过滤约束；<br/>3. 临时盯盘价位在个股页点「记一笔」写入「随心记」（如「跌破 28.5 提醒」），后台最小化照常收系统通知，到点可点「让 AI 看看」核对实时分时；<br/>4. 在「沪深港通」查看成交榜与资金流，浏览到同花顺个股页时可点顶部桥接条一键在本软件打开个股分析。 | 盘中分时与未收盘日线仅用于已定计划的执行触发与底仓风控，不把盘中脉冲视作收盘突破定论；`14:57` 后停止做T新开仓。 |
| **④ 盘后对账与选股**<br/>`15:05–17:30` | **策略选股 · 趋势筛选**<br/>专业复盘 · 今日驾驶舱（盘后） | 1. `15:10` 收盘数据落定后运行「策略选股」（全市场沪深京非 ST 分批扫描，依托本地日线库收盘快照增量补齐，界面实时展示已抓取/已计算进度、命中数与预计剩余时间）；<br/>2. 按需运行「趋势筛选」检验 2–6 周上升趋势形态并冻结新一轮次日计划；<br/>3. 在「专业复盘」或「今日驾驶舱（盘后模式）」对已有冻结计划进行盘后对账（处于入场带、上方偏离或已破止损）。 | 核查选股覆盖说明（是否存在板块名单缓存兜底、停牌新股或单股读取失败）；实际成交与原冻结计划分开登记，不篡改历史计划原价。 |
| **⑤ 晚间深研与归档**<br/>`19:00–22:00` | **AI 选股 · AI 问股**<br/>专业复盘 · 回测中心 · 数据备份 | 1. 在「AI 选股」用 1–4 套模型 +「实测胜率」框架对策略候选或「我的股票」并行打分排雷，关注「模型分歧」与硬规则封顶提示；<br/>2. 对重点标的进入「AI 问股」，自由叠加 1–3 种分析打法（如「底部反转 + 风险收益比」）做多轮数据核验，并在「回测中心」用单股/共享现金组合回测检验历史样本外表现；<br/>3. 在「专业复盘」生成 AI 市场复盘，点击「回看上次判断」复核前日结论兑现率，保存当日复盘档案；<br/>4. 将次日关键观察点设入「随心记」定时/价格提醒，确认「设置 → 数据备份」已加密同步至网盘目录。 | 形成次日明确的三情景预案（进攻 / 分歧 / 防守）与最多 2–5 只核心跟踪标的，完成当日研究闭环。 |

## 2. 执行前核对清单

每次将研究候选转化为次日计划或实际委托前，逐项确认以下边界：

- [ ] **标的与状态真实**：6 位代码、市场（沪深主板 / 创业板 20% / 科创板 20% 且 200 股起 / 北交所 30% 且 100 股起）与交易状态已核对，非演示预览数据。
- [ ] **数据日期与复权明确**：已确认日线截止日为最新完整交易日，分清「不复权原价（交易所限价与真实成交额核验）」与「前复权价格（长期均线趋势比较）」，未把接口抓取时间误当成交时间。
- [ ] **市场关口与公告排雷**：已在「专业复盘」确认中证全指 `MA60` 市场关口状态，并核查近 30 日公司公告无立案、退市警示、大额异常减持等一票否决风险。
- [ ] **价格边界完整冻结**：入场参考区间、结构止损位、单笔最大风险占比与失效退出条件均已明确记录；缺止损依据的标的不开新仓。
- [ ] **仓位与同业集中度受控**：同一股票命中多套策略只算一份标的风险，不重复叠加仓位；同板块持仓敞口与账户总风险不超过预设上限。
- [ ] **异常与未成交预案清晰**：遇一字涨停无法买入、跳空越过入场上限、停牌或跌停无法按原价止损时，按预设规则放弃或顺延处理，如实记录偏差原因。

## 3. 单笔计划与执行复盘记录模板

可将以下字段记录在软件「随心记」、「复盘档案笔记」或外部台账中，用于月度归因：

| 记录模块 | 建议保留字段 |
| --- | --- |
| **基础身份** | 日期、6 位代码与简称、所属同花顺行业/主线题材、市场板块（主板/双创/北交）。 |
| **信号来源** | 命中策略名称与版本、全市场选股数据日、AI 框架基础分 / 模型综合分 / 所用分析打法结论。 |
| **冻结计划** | 计划入场区间、初始止损价、计划股数、单笔风险占净值比、结构失效条件。 |
| **实际执行** | 竞价/盘中实际委托与成交均价、股数、双边税费与滑点；若放弃执行则注明原因（高开超限 / 破位 / 市场关口关闭）。 |
| **盘中做T（如有）** | 底仓可卖股数、正T/倒T方向、开平仓价、扣除佣金印花税后的净落袋差额、是否有未完成跨日残留。 |
| **退出与归因** | 退出日期与触发原因（止盈 / 跌破止损 / 连续两日破 MA20 / 到期退出）、净盈亏、是否严格遵守原计划、改进要点。 |
