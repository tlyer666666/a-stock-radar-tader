# 趋势选股与专业复盘升级说明

A股雷达 1.3 使用说明  2026年9月30日

本次按你的六项反馈调整软件：清理常驻口号，说明趋势选股的实际筛选过程，重做专业复盘的判断顺序，将策略信号扩展到24条，并把观察池改为左侧连板数、右侧个股。选股目标仍是全A股剔除ST，关注近期涨停后的上涨趋势，研究2至6周波段。

## 1 趋势涨停究竟在选什么

这套方法先寻找最近出现过收盘涨停的股票，再确认其上涨结构仍在，最后等待新的转强条件。涨停是资金关注的线索，不是买入指令。价格仍在上涨，但没有再次转强形态，或止损距离不合适，只进入观察；全部必要条件满足后才生成次日复核的价格计划。

| 筛选环节 | 实际检查 |
| --- | --- |
| 证券范围 | 沪深北A股；剔除ST、退市等风险名称。 |
| 数据可用 | 名单完整性、日期顺序、价格、量额和复权资料。个股需要至少250根有效日线。 |
| 近期涨停 | 最近15根交易日内有收盘涨停，按板块限价规则或明确限价字段核对。 |
| 上涨趋势 | 收盘高于MA20，MA20高于MA60且高于5日前；20日均额至少2亿元，涨停锚点支撑未失效。 |
| 形态触发 | 按所选策略检查回踩、突破、动能、量价等具体条件；不同策略各自判断。 |
| 价格风险 | 市场关口、参考止损、最低及最高入场价等条件必须成立；不能因涨停直接跳过。 |

### 为什么上一版像空壳

原趋势模块独立请求东方财富名单与日线，没有使用其他模块的数据源回退。本机实测请求被服务端断开，结果并不能说明全市场没有合格股票。这次把来源状态、逐层通过数量和未通过原因放到结果流程中，数据缺失与规则不合格分开显示。

六级计数按股票去重；同股命中多个策略不会重复累计。联合扫描的技术与风险层表示至少一个所选策略通过，不表示所有策略共同通过。完整名单也不等于每只股票的数据都足够。

## 2 使用时先看哪些信息

### 趋势筛选

选择扫描策略后启动全A股扫描。先检查数据截止日、来源状态和覆盖，再查看筛选过程各级数量。部分数据或扫描取消时，已有候选可以研究，但不能宣称全市场已筛完。无候选时，应先看失败原因，而不是立刻放宽条件。

侧栏品牌大字、2至6周副标题以及参数快照提示不再常驻。筛选原理改为按钮按需展开；参数、计划快照、CSV导出和个股分析仍保留。修改下次扫描参数不会自动修改已保存计划的原价格。

趋势页保留八种策略：原版趋势、趋势质量、MACD零轴金叉、BOLL收口突破、DMI趋势强化、OBV量价突破、KDJ趋势金叉和均线回踩再起。默认联合扫描质量版及六种指标策略；这与策略信号页的24条形态和组合是两个研究入口。

### 专业复盘

主页面按五步组织：数据是否可用、市场与板块、阶段与关键证据、冲突与失效、次日条件情景。先确认哪些事实可观察，再解释判断，不再用总分直接输出入场或仓位。

个股阶段使用真实日线的MA20、MA60、均线斜率和涨停锚点。市场以同日中证全指与完整MA60比较。缺日线或日期错位是不可判；有足够数据而跌破市场关口是规则不通过。即使市场资料缺失，已经取得的个股趋势事实仍然展示。

旧八维、二十因子和五日历史样本保留在折叠详情中。相关指标不会因为数量多而变成多张独立赞成票。缺止损与目标时，不再按现价95%和1.8倍风险补造价格；旧综合分也不再给出60至80%的行动仓位。旧档案保留原内容，不用现在行情回填过去结论。

### 观察池的连板梯队

板数从高到低排列，左侧显示几板和该层股票数，右侧排列名称、代码、所属板块、首次封板、开板次数和换手率。排序只在同一板数层内生效，不再把不同板数混排。缺失值显示待补，真正的零次开板保留为0次。

同一批数据只使用最新日期，冲突的重复连板记录不归入梯队。无日期的旧数据会标注日期待核验。原有T加1至T加10观察与点击个股分析继续保留；连板高度用来描述市场结构，不代表应当追高买入。

## 3 策略信号新增六种组合

原有14个基础形态和4个组合保留，新增6组后共24条，其中组合为10条。以下组合参考通达信公式函数和同花顺公开指标教学，由本项目独立组合实现，不是平台官方荐股或未经授权复制的商业公式。

| 新增组合 | 必须同时满足的主要条件 |
| --- | --- |
| MA10回踩与MACD恢复 | 原MA10回踩形态成立；DIF高于DEA且DEA大于0，MACD柱较前日增加。 |
| 二次突破与BOLL扩张 | 原二次突破成立；昨日带宽不高于此前60日带宽中位数；由轨内越过昨日上轨。 |
| 二次突破与OBV确认 | 原二次突破成立；方向成交量OBV与收盘价格均突破各自此前20日高点。 |
| 回踩收复与DMI强化 | 原MA10回踩或均线收复成立；PDI高于MDI，ADX至少20且比昨日上升。 |
| 地量修复与KDJ金叉 | 原地量阳线修复成立；K由不高于D转为高于D，K不超过80且收盘上升。 |
| 缺口守卫与均线突破 | 原缺口守卫成立；MA5高于MA10高于MA20高于MA60，突破昨日高点，量比1至2.5。 |

### 共同条件与参数

新组合共同要求最近80根与基准交易日对齐、OHLC与量额有效、近期15日涨停、收盘高于MA20高于MA60且MA20上升、均线偏离不超过10%，并保留锚点支撑和原风险否决。缺量额、日期错位或无价格限制日，不以普通涨停信号放行。

MACD参数12、26、9；BOLL为20日和2倍总体标准差；DMI为14日滚动方向指标及6日ADX均值；OBV参照20日；KDJ为9、3、3并以50初始化；均线为5、10、20、60日。固定配置与来源记录在strategy-signal-combinations.json，六组版本均为1.0.0。

### 怎样判断是否值得用

更复杂、组合更多，并不自动提高胜率。先看各组是否有足够独立历史样本、样本外表现和走步检验，再看当前是否满足全部必要条件。新增组合继续受样本量、独立验证、终端留出与多重试验门槛约束，不能因为缺少结果就降低发布标准。

策略信号页使用近期候选池及有上限的研究样本，五日结果仍是短期诊断；它不是全市场全覆盖，也不能验证2至6周账户收益。目标波段的效果仍需独立、含成本与成交限制的真实检验。

## 4 数据来源与执行边界

### 真实行情如何核对

趋势取数修复采用可核验的回退路径：备用全A名单逐页核对数量与重复；备用原始日线需要真实成交额和成交量，并与另一来源的原始价格交叉检查。明确标为前复权的序列才用于复权输入，不把原始价格冒充前复权，不用价格乘成交量伪造成交额。

市场基准仍为中证全指000985。基准只参与价格、均线和相对强弱计算，因此允许指数量额为空，但日期和OHLC必须合格。个股的成交量和成交额要求没有随之放宽。取消后重启的任务使用独立来源记录，旧请求不能混入新扫描。

北交所等证券若来源只返回普通日线、没有明确前复权序列，会显示不可用或部分覆盖。新股不足250根、缺失公司行为与官方限价资料等限制同样保留。来源成功、程序能运行和收益已验证，是三件不同的事。

本机90秒有界实测已载入5571只证券，其中202只按名单规则排除；处理总数275包含这202只。73只完成原始日线核验，10只通过近期涨停，2只通过上涨趋势，2只触发技术条件，0只通过最终风险层。当时市场关口不通过。测试按时主动取消，不能据此宣称全市场历史扫描完成或全市场没有机会。

### 账户与退出规则保持原方案

趋势计划的单笔计划亏损上限为净资产0.5%，单股15%，同业25%，总仓60%，最多6只。同股命中多个策略不能重复叠加仓位。成交价需在对应计划的冻结区间内，并另外核对费用、交易权限、数量单位、公告与可成交性。软件不自动下单。

目标10至30个交易日不是至少持满10日。收盘跌破冻结止损，或持有后连续两日低于各日MA20，安排下一可交易日退出；第29日收盘安排第30日开盘退出。停牌、跌停和跳空可能延迟退出或扩大损失；复盘的结构低点不能擅自覆盖旧计划止损。
