# 趋势波段扩展：规则与实现约定

基于用户已确定的桌面 Word 方案 v1.1：全市场 A 股，剔除 ST / *ST，近期涨停且趋势上涨，目标持有 2–6 周。以该方案作为默认工作台，不把新规则混入原有固定五日回放或宣称已验证的策略。

## 规则

- 日线收盘后计算。原始日线负责涨停识别和实际报价；前复权日线负责均线、支撑、ATR。以最新日期的原始/复权收盘比将参考价换回实际价格。
- 沪深主板、创业板、科创板、北交所逐页取名单并去重；排除 ST、*ST、退市名及非 A 股。至少 250 根有效日线；停牌、陈旧、字段缺失等单列，不能算筛选未命中。
- 最近 15 根交易日（d=0..14）有收盘涨停，最近一次为 t0。C > MA20 > MA60，MA20 > 五根前 MA20，t0 后所有收盘 >= t0 最低价，20 日均成交额 >= 2 亿元。信号还要求 C/MA20-1 <= 10%。
- A 缩量回踩：d=4..14；此前三根至少一根最低价在该日 MA20 的 98%..102%，三根平均成交量 <= t0 成交量的 70%；当日收盘 > 前一根最高价且成交量 >= 此前五根均量。
- B 整理突破：d=4..11；整个 t0+1..信号前一日的 3..10 根，最高/最低-1 <= 10%，平均量 <= t0 量的 80%；当日收盘 > 整理最高价且量 >= 此前五根均量的 120%。
- 同时 A/B 只显示一只，风险参考使用 A 的三根最低价。ATR14 为最近 14 根 TR 的算术平均。S=max(t0最低价, 整理最低价-0.5ATR14)，Pmax=min(1.03C,S/0.92)。仅当 S < Pmax 才有参考入场区间 S < P <= Pmax。
- 候选排序：20 日相对中证全指收益降序，缺失相对收益排尾，再按成交额、代码。中证全指低于 MA60 时暂停新开仓，基准缺失时未知。所有候选是研究观察结果，需复核次日交易状态、公告和权限。
- 退出规则由计划复核器基于手动输入计算：收盘低于 S、持仓后连续两根低于 MA20 时下一可交易日退出；第 29 日收盘安排第 30 日开盘退出。此版本不自动交易，不把这一说明冒充已实现的持仓执行器或回测。

## 数据边界

公开 K 线通常缺少逐日官方涨停价、历史特殊交易状态和股本变化记录。实现允许常规 10% / 20% / 30% 限幅按原始价格推算，并明确标记“规则推算，待核验”，不能称官方确认。发现近 20 日复权因子变化时不生成量价信号，避免股本变化造成量比失真。全市场扫描范围与官方事件核验完整性是两件事，均须披露。未完成分页、历史请求失败、无成交额或复权失败时一律显示部分覆盖；无数据不等于无候选。

## 实现计划

1. 独立纯函数引擎 `electron/trend-screener-engine.cjs` 及行为测试。输入证券、原始与复权日线、基准、截止日期；输出观察候选、证据、参考风险区间或明确排除/数据不可用原因。
2. 独立任务服务 `electron/trend-screener-service.cjs`：完整分页、六路有界历史加载、按日期缓存、单任务、进度查询与取消。保留各板块应取/实取与失败明细，不设 300 只或其他候选数量上限。
3. `TrendScreenerView`、共享类型和浏览器预览：趋势波段导航、手动扫描/取消、覆盖统计、A/B/观察筛选、证据明细、可打开原有个股分析。预览明确为演示数据。
4. 主进程可信 IPC 与 preload 接入，默认公开行情适配器遵循失败关闭原则；测试、类型检查、构建、浏览器操作检查；桌面 Word 增补实际实现和待验证边界。

验证重点：分页重复/缺页、ST 与各板块、15 日边界、信号日前区间排除当天、涨停重置、只触板不计、分红/股本变化、缺数、未来数据、取消与并发，接口不写入任何实盘或模拟订单。

## 0.10.0 方案融合验收

- 默认工作台、侧栏品牌及顶部规则围绕涨停趋势；原策略和实时刷新不再误导此模块，原功能按需打开。
- `src/trendPlan.ts` 精确实现 Word 第3节仓位公式、15%/25%/60%/6只上限、0.5%计划亏损预算、申报单位、现金/费用及重复持仓阻止。
- 同一文件实现收盘低于冻结S、两根持有期收盘低于各自MA20、第29个持仓交易日触发下一开盘退出的复核。交易日数和日线为手工录入，输入缺失/口径未核验时不输出已通过结论。
- `src/trendWorkspace.ts` 保存带日期、来源性质和冻结价格的计划快照，保存数字测算草稿，CSV保留数据日期/规则证据/DEMO标识并转义公式。核验勾选不是历史事实，每次重新打开需复核。
- 方案算例明确标示虚构，不写入真实候选、不影响扫描统计。网络失败仍可验证数学公式，不能据此生成真实证券信号。
- `qa/run-trend-screener-smoke.cjs` 验证默认入口、筛选/搜索/证据、保存并刷新恢复、CSV、Word算例及第29日退出、窄屏、取消/异常。`qa/run-trend-desktop-smoke.cjs` 验证交付应用实际入口及原生IPC。
- 行情源不可用时停止请求并展示源端/失败阶段/重试说明；不自动降级到缺成交额或复权信息的源。

尚未实现：券商账户同步、实盘自动委托、自动抓取持仓日线逐日复核、官方交易日历与历史风险状态、完整历史成分组合回测。当前方案是可交互的筛选与人工计划/复核工具，软件测试不代表策略收益。
